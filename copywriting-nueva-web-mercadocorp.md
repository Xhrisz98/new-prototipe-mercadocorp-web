# Copywriting & SEO — Nueva Web MercadoCorp

**Objetivo de este documento:** todos los textos necesarios para las 14 páginas del sitio, optimizados para conversión y SEO, con estrategia de enlazado interno para maximizar el tiempo dentro del sitio y reducir el rebote.

**Principios aplicados en todo el sitio:**
- **AIDA + prueba social** en cada página de servicio (Atención → Interés → Deseo → Acción)
- **Un solo CTA primario por página** (evita parálisis de decisión), con un CTA secundario de "quedarse navegando" (link interno) para retener antes de pedir el paso de conversión
- **Cada página enlaza mínimo a 2 páginas más** del sitio (retención / reduce bounce rate) — detallado al final de cada ficha
- **Keywords objetivo** pensadas para búsqueda en Ecuador/LatAm B2B: "agente de IA para empresas Ecuador", "automatización de procesos Ecuador", "CRM personalizado Ecuador", "consultora tecnológica B2B Quito", etc.
- Tono: directo, sin jerga vacía de agencia, orientado a dolor de negocio → solución concreta (igual estilo que ya validó el sitio actual)

## Resumen de estrategia de retención (enlazado interno)

Cada página del sitio enlaza como mínimo a: (1) una página "hermana" del mismo pilar, (2) el hub del pilar, y (3) Casos de Éxito o Contacto. Esto crea un recorrido natural:

`Inicio → Auditoría Digital (gancho) → Tecnología o Marketing (hub) → servicio específico → Casos de Éxito → Contacto`

Ningún CTA de página de servicio apunta directo a Contacto sin antes ofrecer un link de "seguir navegando" (a Casos de Éxito o a otro servicio relacionado) — esto es lo que sostiene el tiempo en sitio antes de pedir la conversión.
